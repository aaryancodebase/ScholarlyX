# Algorithms
- Boolean retrieval: AND, OR, NOT and parentheses over term postings.
- TF-IDF: sparse term weighting with cosine similarity.
- BM25: term-frequency saturation, inverse document frequency and length normalization.
- Semantic: normalized Sentence Transformer embeddings and cosine similarity.
- Hybrid: 45% normalized BM25 + 55% normalized semantic scores.
- Text analytics: LDA topic modelling and TF-IDF K-Means.
- Evaluation: Precision@K, Recall@K, MAP and NDCG@K. Meaningful evaluation requires human-labelled relevance judgments.
